# Relatório — A dança que a cidade não conta

Levantamento sobre as organizações de dança social do município e do estado do Rio de Janeiro,
produzido para o encontro **Movimento Social da Dança RJ** (10/09/2026, Cinelândia), a convite da
vereadora Verônica Lima.

Publicado pela Sede do Movimento. Todos os números são reproduzíveis a partir de fontes públicas
(Mapa das OSCs/IPEA, API do Salic/MinC, Diário Oficial do Município do Rio).
